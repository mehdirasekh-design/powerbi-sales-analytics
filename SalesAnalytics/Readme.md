Sales Analytics Dashboard | Power BI
Project Overview
This project is a Power BI sales analytics portfolio project designed to demonstrate business intelligence, data modeling, data transformation, and data visualization skills.
The dashboard provides an interactive view of sales performance, customer behavior, product performance, and geographic trends.
Objectives
•	Analyze sales performance using business KPIs.
•	Identify high-performing products and customer segments.
•	Evaluate geographic sales distribution.

•	Demonstrate data modeling and DAX skills.
•	Translate data into actionable business insights.
Tools & Technologies
•	Microsoft Power BI
•	Power Query
•	DAX
•	CSV datasets
•	SQL / T-SQL, where applicable
